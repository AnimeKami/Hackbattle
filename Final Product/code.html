medical_services Doctor's Clinical Note for Parents

Pupillary Light Reflex (PLR) evaluates cranial nerves II (optic) and III (oculomotor). Normal pediatric latency ranges around 200–600 ms with symmetrical constriction amplitude exceeding 1.2 mm (~30–55%).

PLR Architecture & Flask Pipeline

Frontend-to-backend data flow, MediaPipe FaceLandmarker, and contour analytics

Flask + OpenCV + MediaPipe ACM/Science Fair Ready
STAGE 1 videocam

Browser Privacy & Capture

User clicks 'Turn Camera On' (explicit permission). 15 FPS frame capture into memory { t, image: base64 } with white screen flash at exactly 2.000s.

Privacy: No silent recording
STAGE 2 send

POST /analyze_session

JSON payload transmission. Validation gate: asserts len(frames) >= 10. Safeguards return HTTP 400 if corrupt or insufficient frames.

Endpoint: /analyze_session
STAGE 3 code_blocks

Flask + OpenCV Decoding

Base64 decoding stream into in-memory buffer, decoded with cv2.imdecode into NumPy BGR ndarray without writing disk files.

In-Memory NumPy Buffers
STAGE 4 face

MediaPipe FaceLandmarker

Iris center & boundary landmarking via face_landmarks[0]. Dual-eye robustness: computes mean (L + R) / 2 or gracefully falls back if one eye blinks.

Dual-Eye Auto-Fallback
STAGE 5 lens

Pupil Contour Analysis

Adaptive thresholding, morphological noise filtering, and minimum enclosing circle estimation. Calculates diameter: diameter = 2 * r_px.

Subpixel Radius Resolution
STAGE 6 ssid_chart

Schema Aggregation & JSON

Calculates baseline median, minimum post-flash constriction, latency, and percentage constriction: 100 * (baseline - min) / baseline. Returns curve coordinates.

Exact 4-Metric Schema
